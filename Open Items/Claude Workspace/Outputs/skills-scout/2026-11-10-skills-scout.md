## Aegis — governance, approvals, agent hygiene
4. **distronode-corporation/mcp-patchbay**: an MCP server that hosts other MCP servers and lets the agent switch them on and off mid-session. Servers marked `confirm` need **a person (not the agent)** to approve each enable, through MCP elicitation. Exact commands are pinned per server. Why it matters: this is a clean, working example of a "requester ≠ approver" gate at the tool-surface level, the Aegis governance-alert pattern applied to connectors. It also offers a way to keep your 100+ connector surface small per session. _Trust: Tier 4 (Nov 9, ★2). The README itself warns that allowing `mcp__patchbay` wholesale approves every hosted tool._ https://github.com/distronode-corporation/mcp-patchbay
5. **LSUDOKO/Apprentice**: an agent that learns a triage task by watching you, proves it with backtests and regression tests, then **earns autonomy on a trust ladder**. Why it matters: a graduated-autonomy model (shadow → suggest → act) with evidence gates, a useful design reference for Aegis approvals and for how Talbot/Turner routines could earn auto-approve. _Trust: Tier 4 (Nov 9, ★0), portfolio/pitch project. Use it for the pattern, not as a dependency._ https://github.com/LSUDOKO/Apprentice
6. **YusufSizmaz/bekci** (`npx bekci`): offline scanner for skills, plugins, MCP servers, hooks, permissions and rules files. It looks for prompt injection (including hidden Unicode), credential theft and typosquatted MCP packages. No network access, no dependencies. Why it matters: it adds what skillwall (pinning) and vibe-shield (rule scan) don't: an **offline, zero-dependency** check, which makes it the safest of the three to run against your exported skill set. _Trust: Tier 4 (Nov 9, ★2, npm-published). Read before running._ https://github.com/YusufSizmaz/bekci

## Recess / K-12
7. **rpg36/parent-school-skills**: two **read-only** Agent Skills, `canvas-grades` (Canvas parent/observer account) and `parentvue-grades` (Edupoint Synergy ParentVUE). Each is one standard-library Python script with a fixed allowlist of read endpoints and no write ability. Why it matters: this is the safe parent/teacher read-access shape Recess will need for Shadow Rock: SIS/LMS read-only, an allowlist, no writes. If Shadow Rock's district uses Synergy or Canvas, it's directly reusable for admin ops. _Trust: Tier 4 (Nov 8, ★0). Credentials are parent logins, so treat it under FERPA discipline and test with your own account only._ https://github.com/rpg36/parent-school-skills
8. **AI-Native-Ventures/jemma**: a learner-profile tutor agent with its own MCP server. The teacher uploads the curriculum and photos of class tests, Jemma marks them and finds each child's gaps, the parent runs a short gap lesson, and the child never sees a score. Why it matters: it matches Recess's math gap analysis / prerequisite-routing thesis almost one-to-one (teacher-fed, gap-first, no scores shown to the child). _Trust: Tier 4 (Nov 10, ★0, design-challenge entry). Use it for the pattern only._ https://github.com/AI-Native-Ventures/jemma
