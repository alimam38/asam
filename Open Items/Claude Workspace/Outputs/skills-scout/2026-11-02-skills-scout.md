## Official / Tier 1

1. **⚠️ Trojanized Claude Code extension 2.1.313 on Open VSX / Cursor (Oct 29, ~09:27–20:35 UTC)** — A tampered `anthropic.claude-code` 2.1.313 (also reported as 2.1.312) was served through the Cursor/Open VSX marketplace for ~11h and planted a persistent SSH backdoor; Cursor says up to 5,000 users were affected. Reports say the official VS Code Marketplace and the Claude Code CLI were not affected, and Anthropic says its own systems weren't breached. **Why it matters:** this is the toolchain behind every lane (Plumbline, Meridia, Aegis code). If any machine runs Cursor, VSCodium or Windsurf with extension auto-update, check now. On Windows look for `%USERPROFILE%\.config\smt.cmd`, a `SysMon` scheduled task or `sysmon.cmd` in Startup, and an `svc-telemetry` key in `~\.ssh\authorized_keys`. If you find any of them, run Cursor's remediation script and rotate your GitHub, Dropbox and API tokens from a clean machine. Updating to 2.1.314 does **not** clean the machine. **Trust:** official-channel incident, reported by Tier 2 press (Reuters, BleepingComputer, Microsoft Security blog, The Hacker News, Sophos). IOC checklist from wmedia.es (Tier 4, consistent with vendor posts). — https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/ · https://www.bleepingcomputer.com/news/security/malicious-claude-code-extension-on-cursor-planted-ssh-backdoors/ · https://wmedia.es/en/tips/claude-code-extension-2-1-313-malware-check
