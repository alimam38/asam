## Top picks (ranked)

### 1. Google will push AI agents onto its Workspace MCP servers from Feb 1, 2027
Google made its Workspace MCP servers and a Workspace CLI generally available on Nov 24, with two usage tiers (Standard, free; Scaled, paid) starting with Gmail, Drive and Calendar. A new **Workspace AI Tools Addendum** says that from **February 1, 2027**, agents that keep calling the Workspace REST APIs directly are held to Standard-tier quotas whatever tier the project pays for. Reported gaps: the Gmail MCP server **can't send email** and the Drive one lacks file-management operations; there's also a 30-day cap on how long agents may retain technical data. HN thread hit 342 points / 303 comments.
- Sources: [Workspace Updates blog](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html) · [Usage tiers doc](https://developers.google.com/workspace/guides/quota-usage-tiers) · [Tech Stackups analysis](https://techstackups.com/articles/google-workspace-ai-agents-mcp/) · [HN](https://news.ycombinator.com/item?id=50653477) · [flaviocopes summary](https://flaviocopes.com/google-workspace-mcp/)
- **Why it matters to Ali:** several of your automations touch Gmail, Sheets, Drive and Calendar through third-party connectors (Composio, FGAC) and scripts that call the REST APIs. After Feb 1 those calls may get throttled, and anything that *sends* mail through an agent could lose its path if it has to move to Google's MCP server. It's a fixed deadline with about 9 weeks of runway, so it's an inventory job now rather than an outage later.

### 2. "Skills over MCP" ships: MCP servers can now carry their own playbooks
Claude Code **2.1.332** adds skills delivered by MCP servers (beta; they show as `server:skill` in `/`) and a new **`PreSkillShellCommand`** hook that can refuse a skill's inline shell commands as it loads. Alongside it, Anthropic reported **700M+ monthly MCP SDK downloads** and new protocol capabilities: background tasks, elicitation (the server asks the user a follow-up through a form), and file uploads to servers coming soon. Commentators flagged the flip side: a server owner can now change the instructions Claude follows without a reinstall or a fresh approval.
- Sources: [Claude Code CHANGELOG 2.1.332](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · [The Decoder](https://the-decoder.com/anthropic-tops-700-million-monthly-mcp-sdk-downloads-and-expands-the-protocol-for-more-autonomous-ai-agents/) · [VentureBeat](https://venturebeat.com/technology/mcp-servers-can-now-deliver-ai-agent-skills-changing-what-companies-approve-when-they-connect-one) · [TechTimes on approval gap](https://www.techtimes.com/articles/331491/20261125/anthropic-launches-skills-over-mcp-beta-server-skills-update-without-reinstall-approval-unstated.htm) · [Boris Cherny on X](https://x.com/bcherny/status/2125292098165612585) _(X via SerpAPI)_
- **Why it matters to Ali:** you run a lot of connectors. This makes them better out of the box, since each server can teach Claude how to use it. It also creates a new supply-chain surface: the playbook can change upstream without you seeing it. The `PreSkillShellCommand` hook is the control point if you ever let server skills run shell commands. For Plumbline, an MCP server that ships its own skills is a cleaner way to deliver an "SIS overlay" to small institutions than a separate skill install.

It follows the confirmed RunPod case logged on 11-24 (`runpod-mcp#202`, a hidden survey instruction) and the week's top AI essay on HN, *"LLM agents work for their parent companies, not for you"* (1,032 pts).
- Sources: [HN thread](https://news.ycombinator.com/item?id=50658093) · [Reddit post](https://www.reddit.com/r/ClaudeCode/comments/1y4qm5o/heads_up_if_you_wire_notions_official) · [Essay](https://michaelharley.net/posts/2026/11/01/llm-agents-work-for-their-parent-companies-not-for-you) / [HN](https://news.ycombinator.com/item?id=50627340)

Taken with pick #2, the pattern is that tool descriptions and tool outputs from vendor servers are becoming a channel for the vendor's interests. Spot-check what your most-used servers return, starting with Notion, before trusting them with unattended routines.

### 4. Claude artifacts can be installed as Mac/Windows desktop apps (beta)
"Install as app" turns an artifact into a desktop app with its own icon and window, notifications and menu-bar presence, under three permission levels: Default, App permissions, and **Full computer access**. It's in beta on all plans; HIPAA-ready orgs are excluded.
- Sources: [claude.com article](https://claude.com/resources/articles/install-as-app) · [MacStories close look](https://www.macstories.net/stories/a-closer-look-at-claudes-mac-apps/) · [HN](https://news.ycombinator.com/item?id=50634369)
- **Why it matters to Ali:** dashboards and trackers you already publish as artifacts (receivables views, Talbot reports) can now live as one-click desktop tools for colleagues who won't open a chat. It's also a cheap way to prototype Plumbline's "dashboard for small institutions" idea. Keep Full computer access off for anything you share.
