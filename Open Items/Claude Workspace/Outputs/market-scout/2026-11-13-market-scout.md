## Top picks (ranked)

### 1. Claude Sheets + Whiteboards (beta), Claude Data (GA), Claude Meetings (beta). Released Nov 10.
- **What:** Anthropic shipped office-style tools inside Claude. **Sheets** has tabs, formulas, drop-downs and tracked edits, and exports to .xlsx/CSV. **Whiteboards** export to Lucid, Miro or Zoho. **Claude Data** is the renamed Claude Dashboards, now GA: it needs a data connector such as a warehouse or CRM, and adds certified queries and live sharing (beta), tracked changes and caching. **Meetings** puts Claude into Google Meet as a visible participant (Team/Enterprise beta). It leaves automatically if an external guest joins, unless an admin allows it. Interactive connectors can now open full apps (Adobe, Atlassian, HubSpot) alongside the chat. Sheets, Whiteboards and Data are on all paid plans. On Enterprise, Claude Data **turns on by default Nov 19**; the setting is in Org settings → Artifacts.
- **Why it matters to Ali:** This hits two lanes at once. (a) For **Plumbline**, Claude Data is now a GA "dashboards over your warehouse" product included in every paid Claude plan. Small institutions that already pay for Claude get basic embedded analytics without buying anything else. Plumbline's edge has to be what Claude Data can't do: Populi-specific models, governed metrics, an accreditation/IPEDS view. (b) For **Turner ops**, Sheets is a native, shareable tracker surface for the Talbot/receivables-style trackers. Meetings is an alternative to the Read.ai → ledger flow, but only for Google Meet calls with no outside guests.
- **Links:** [Anthropic announcement](https://claude.com/blog/sheets-whiteboards-data) · [TechCrunch on Meetings](https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/) · [HN discussion (294 pts)](https://news.ycombinator.com/item?id=50443716) · [Reuters](https://www.reuters.com/technology/anthropic-brings-claude-google-meet-tackle-tasks-live-2026-11-10/)

### 2. Claude Code 2.1.323: Code Mode, plugin version gates, a large permission/sandbox hardening pass, and a breaking removal
- **What:** New **Code Mode** (experimental, opt-in): Claude writes JavaScript to call its tools instead of making one tool call at a time. It can be turned off org-wide. Plugins can now declare `engines["claude-code"]` in `plugin.json`, and versions outside that range won't install or load. `claude plugin validate` now type-checks TypeScript hooks. About 25 fixes close permission and sandbox gaps: `Bash(ls*)`-style wildcard bypasses, `sudo`/`env` wrappers dodging deny rules, Write/Edit reaching `Read`-denied paths, the sandbox switching off mid-session, and "don't ask again" offered on writes to `.claude`/`.git`. That last fix pairs with the Apiiro secrets finding from the Nov 10 digest. MCP calls that hit `TOKEN_EXPIRED` now prompt you to sign in again instead of failing. **Breaking:** `subagentStatusLine` was removed with no startup warning. Open regression [#109446](https://github.com/anthropics/claude-code/issues/109446) has 16 👍; it says no mod render site can replace the row.
- **Why it matters to Ali:** You build plugins and skills. Add `engines` to anything you ship, and run `claude plugin validate --strict` on any TypeScript hooks. If any status line or mod reads subagent rows, it went blank on 2.1.323. Code Mode is worth one controlled try on a tool-heavy job, such as a Populi read with many calls.
- **Links:** [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · [Code Mode docs](https://code.claude.com/docs/en/code-mode) · [Issue #109446](https://github.com/anthropics/claude-code/issues/109446) · [HN (Nov 13)](https://news.ycombinator.com/item?id=50477704)

### 3. Corelight: a "pinned" MCP server isn't actually pinned when it launches through uvx/npx
- **What:** One community MCP server with an unchanged config ran with **15 different dependency sets in 5 weeks**; 23 of its 69 packages changed version. The uvx launcher installed from declared dependencies, skipped the hash-pinned lock file, and pulled fresh packages from PyPI on every rebuild. Of 35 servers Corelight reviewed, **23** recommend an install that pulls from a public registry on every launch. Five servers frozen to a commit plus a hash-locked install ran 457 times with no drift. The article also notes a Shai-Hulud worm variant that hit MCP-themed PyPI packages in June.
- **Why it matters to Ali:** This is concrete supply-chain hygiene for your self-hosted MCP stack (Docker/NAS, Composio-adjacent servers). Commit-pinning a server is not enough; the install also has to be hash-locked. It's a cheap audit, and it follows the trojanized Claude Code extension story in the Nov 6 digest.
- **Links:** [Help Net Security](https://www.helpnetsecurity.com/2026/11/13/corelight-mcp-server-supply-chain/) · [GBHackers (related Corelight finding)](https://gbhackers.com/corelight-reveals-ai-security/amp/)

### 4. The agent-commerce layer firms up: pay-per-call APIs, enterprise MCP servers, and sites closing to agents
- **What:** The **Brave Search API** now accepts **x402** pay-per-request payments in USDC on Base: no account or API key, about $0.005 per request. The endpoint returns HTTP 402 with a price, and the agent pays and retries. **Schwab** launched MCP servers that let client AI act on trading accounts, going beyond read-only. **United Airlines** banned AI agents from booking flights on travelers' behalf (671 pts on HN). **Pomerado** (YC F26) turns any website into an MCP server. Darwinbox shipped a Claude connector with 280+ HR tools.
- **Why it matters to Ali:** The pattern since October continues: regulated incumbents (finance, HR) ship their own MCP servers, while consumer sites restrict agents. For Turner-scale vendors (Populi, QuickBooks, Gusto), the likely next step is a vendor MCP server with a write-gated tier, not an open API. x402 is the first real "no API key" payment path an agent could use for paid data like search.
- **Links:** [Brave blog](https://brave.com/blog/search-api-agentic-payments/) · [Schwab MCP (FinanceX)](https://www.financexmagazine.com/post/schwab-mcp-server-links-clients-ai-to-their-trading-accounts) · [United ban (CBS)](https://www.cbsnews.com/news/united-airlines-bans-ai-agents-booking-flights/) · [Pomerado Launch HN](https://news.ycombinator.com/item?id=50455811) · [Darwinbox connector](https://www.bignewsnetwork.com/news/279426854/darwinbox-launches-claude-connector-with-280-hr-tools-across-the-employee-lifecycle)

### 5. Atuin Threads: search, resume and fork agent sessions across machines (self-hostable)
- **What:** Atuin 18.24+ captures Claude Code, Codex, Pi, OpenCode and Omp sessions. Sync is end-to-end encrypted, through hosted sync, a **self-hosted server**, or local only. You can resume a session on another machine or fork it into a different harness. It installs an MCP server with `atuin mcp install claude`. Team sharing is not out yet. The blog post is dated Oct 27; it got HN traction on Nov 11 (234 pts).
- **Why it matters to Ali:** This targets your multi-surface problem directly: sessions spread across the Windows PC, cloud runs and Cowork. A self-hosted sync server fits the NAS, and capture is opt-in, so it's low-risk to trial.
- **Links:** [Atuin blog](https://blog.atuin.sh/threads-agent-sessions/) · [HN](https://news.ycombinator.com/item?id=50453637)
