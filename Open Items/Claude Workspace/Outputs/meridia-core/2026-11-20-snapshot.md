| No service token | HTTP 403 | Access policy is active and blocking anonymous requests |
| Service token, websocket upgrade (HTTP/1.1) | HTTP 502 `error code: 502` | Access **accepted** the token and forwarded the request; it failed past the edge |

**Most likely cause:** the tunnel connector cannot reach `192.168.0.160:5433` (NAS-side routing, e.g. cloudflared in Docker without host networking), or the ingress rule for db.meridiahq.com is not a `tcp://` service.
